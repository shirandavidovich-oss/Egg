# 12 עולמות החשמל והמגנטיות — תוצר מקורי לקלוד

חבילת הרחבה מוכנה לפיתוח למשחק היצור מהביצה. בהשראת **מבנה לימודי** בלבד של חוברת פיזיקס לחשמל ומגנטיות שהועלתה לשיחה. ללא העתקת ניסוחים, תרגילים, תרשימים או סריקות ממנה.

## מה קיים
- **12 עולמות** עם **7 סיטואציות שונות בכל עולם** = 84.
- **4 משימות מתוכננות לכל סיטואציה** = 336 משימות — בשלב זה מפרטי משימות; לא 336 מיני־משחקים גמורים.
- **26 מודלי פיזיקה מחושבים בפועל** (`engine/physics.mjs`), מבוססי מערכות אידיאליות ואירועי מדידה.
- **אב־טיפוס אינטראקטיבי, רספונסיבי ועובד** עם עולם/מצב, סיפור, מטרה, מחוונים, סקיצת Canvas סכמטית, תוצאות, חיזוי מגמת שינוי, מטבעות דמו ושמירה מקומית במצב שמאפשר זאת.
- `docs/` מכילה הוראות לשילוב, סקיצות למכניקות, חוקי פיזיקה, כללי מקוריות ובדיקות קבלה.
- `previous_work/mechanics_worlds_original_system_for_claude.zip` — עותק של חבילת המכניקה המקורית כדי לעזור במיזוג, **לא להחלפת הקוד שכבר פועל**.

## לפתוח עכשיו
פתח `preview_offline.html` בדפדפן. זהו קובץ יחיד שאינו זקוק לשרת או חיבור אינטרנט.

או מתוך התיקייה:
```sh
node tests/test_physics.mjs
python -m http.server 8000
```
פתח `http://localhost:8000/demo/`.

## איך לתת לקלוד
העלה את ה־ZIP לפרויקט המשחק של קלוד, ובקש שיפתח קודם את `CLAUDE_START_HERE_HE.md`, יסרוק את קוד המשחק הקיים ויתאים את עולם החשמל בלי לפגוע במכניקה. אל תעלה את חוברת פיזיקס למשחק.

## מה עדיין לא קיים
זה **לא APK**, לא משחק סופי של 84 מיני־משחקים, ולא 336 השלמות מוכחות. האנימציות בדמו סכמטיות, ואינן מציגות מסלול מדויק בזמן. שמירת מטבעות בדמו נפרדת מארנק המשחק הקיים. אחרי ההטמעה קלוד צריך לממש את מכניקות הסצנות והמשימות, שיקולי נגישות, מדדים, סיפורי דמות, ושכבת הסימולציה בזמן.
