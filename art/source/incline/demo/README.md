# הדגמה אינטראקטיבית
פתח את `demo/index.html` בדפדפן. כשהקבצים מחולצים יחד מתיקיית ZIP, כל ה-assets ו-`data.js` זמינים דרך נתיבים יחסיים. אין צורך ברשת או בשרת כדי לראות את ההדגמה. אם הדפדפן חוסם חלק ממקורות ה-file://, פתח שרת HTTP פשוט מתיקיית השורש של החבילה, למשל: `python -m http.server 8000` ואז בקר ב-`http://localhost:8000/demo/`.

- זווית המדרון ניתנת לגרירה במחוון או בקצה המדרון. זווית בטווח 0–55°.
- הצגת חצים 'כוחות אמיתיים' / 'רכיבי כבידה'; כל חץ מחושב בזמן אמת ולא נלקח מתמונה.
- שינוי חומר המשטח מותר. מאפייני **היצור** הם read-only.
- 7 שלבים, תגמול מטבעות פעם אחת בלבד לכל גילוי, שני מדי התקדמות, חזרה לשלב קודם ושאלת בדיקה.
- השוואת דמות אחרת היא **חיזוי להדגמה בלבד**, ולא שינוי בעלות; החלפה אמיתית דורשת backend ואישור של שני שחקנים.
- זוהי **הדגמת UX** לבדיקה ולצפייה, לא אפליקציה מוכנה ולא חומר שעומד לבדו במקום הקוד והבדיקות בפרויקט המקורי. זמני שלבים/תנועת מצלמה/עומק אנימציות נשארים למימוש משופר באנדרואיד.
- נתוני הדמו (במיוחד התקדמות כללית התחלתית) הם בדויים, לתצוגה בלבד; לא לכתוב אותם לפרופיל שחקן אמיתי.
