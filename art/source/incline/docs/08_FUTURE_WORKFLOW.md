# תהליך קבוע לפיתוח כל משחקון חדש
1. המשתמש ואני בוחרים נושא בפיזיקה ובונים אינטראקציה קצרה, פיזיקלית נכונה, שמפתיעה ומצחיקה.
2. אני מכין אוטומטית ZIP עם briefing לקלוד, עיצוב לבן-עיפרון, נכסים גרפיים, קוד/דמו אם מתאים, מפרט נוסחאות, שלבים ושאלות, נתונים ובדיקות.
3. המשתמש מעלה לקלוד, בודק APK/משחקון בפועל וחוזר עם תיקונים או תוצאה.
4. אם יש תיקונים: ZIP patch/revision ששומר הכל; אם אין: ממשיכים לפרק הבא לפי מפת תוכנית בגרות מלאה.
5. כל פרק שומר עקרונות רוחביים: הדמות גוף פיזיקלי קבוע, החלפה עם חבר, מטבעות, התקדמות כללית ונושאית, mastery סמוי, למידה חופשית קצרה, עברית RTL ושפה עיצובית אחידה.
אין צורך שהמשתמש יבקש שוב 'קובץ ZIP' בכל משחקון — זה תהליך קבוע.
