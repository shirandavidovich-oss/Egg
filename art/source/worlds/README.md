# עולמות המכניקה — חבילת תוכן וקוד לקלוד

חבילה מקורית חדשה בהשראת *מבנה הידע בלבד* של חוברת מכניקה שצורפה לשיחה. **אין בחבילה צילום, ניסוח, תרגיל או איור מועתק מן החוברת.**

## מה קיים בפועל
- **12 עולמות, 84 סיטואציות מקוריות ו־336 הגדרות משימה** בפורמט JSON.
- **20 מודלי פיזיקה מחשבוניים** כקוד JavaScript תקף; חישובים לפי משתנים בסצנות.
- **אב־טיפוס דפדפן עובד**: מפת 12 העולמות, 84 סיטואציות לבחירה, מחווני ערכים, ציור סכמטי לכל משפחת מצבים, חישובים, בדיקת תחזית ראשונה, וניקוד/שמירת demo מקומיים. לא מיני־משחק מלא, לא קוד המשחק הקיים, לא APK.
- **32 בדיקות רפרנס** לפיזיקה ולנתונים (עברו ב־Node 22 בעת ההכנה).
- **הוראות מפורטות לקלוד** לבנייה במוצר, שמירת פרקי קפיץ/מדרון קיימים, התקדמות ועיצוב.
- `previous_work/incline_friction_18_scenarios_for_claude.zip` — עותק מחבילת המדרון שבנינו קודם, כדי שקלוד יוכל לשמר ולשלב את 18 המצבים והמשימות בלי לאבד את העבודה הקודמת.

## פתיחה מיידית (בלי שרת)
פתחו את `preview_offline.html` בדפדפן — כל הקוד, המסכים והנתונים כבר משולבים בדף אחד. אין צורך להתקין דבר.

## הוראות הרצה
מחלצים ZIP. מתוך תיקיית השורש של החבילה:

```bash
node tests/test_physics.mjs
python -m http.server 8000
```

פותחים בדפדפן `http://localhost:8000/demo/`. נדרש שרת מקומי קטן כי המערכת נטענת באמצעות ES modules ו־fetch של JSON; פתיחת `index.html` ישירות דרך `file://` עשויה להיחסם. אין תלות ב־npm.

## סדר קריאה לקלוד
1. `CLAUDE_START_HERE_HE.md` — הסבר מה המשתמש רוצה ומה אסור לשבור.
2. `docs/UX_GAMEPLAY_HE.md` — חוויית המשחק.
3. `docs/WORLD_MAP_HE.md` — תוכן סיטואציות.
4. `docs/PHYSICS_CONSTRAINTS_HE.md` — מודלים מדעיים ומגבלות.
5. `docs/INTEGRATION_ACCEPTANCE_HE.md` — הדרך ליישום וקריטריוני הצלחה.
6. JSON + קוד + בדיקות.

**הערה על היקף:** זהו בסיס עבודה מקיף הכולל אב־טיפוס מחושב ותוכן מקורי. שלוש משימות מתקדמות בכל סצנה, משחקיות בשימוש בספרייטים הקיימים, משחק אמיתי בזמן וחיבורי APK — עדיין חלק ממשימת הפיתוח לקלוד.
